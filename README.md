# Windows Event Log Investigation Lab

Hands-on Windows Security Event Log analysis for SOC Analyst skill development.

## Overview

This repository documents practical investigation work focused on the Windows Security log — the core native telemetry source used in almost every Windows-related SOC investigation.

## What’s Included

| File | Description |
|------|-------------|
| `Windows_Event_Log_Lab_Report.docx` | Portfolio lab report (Word) |
| `Windows_Event_Log_Lab_Report.md` | Same report in Markdown |
| `Windows_Event_Log_Lab_Guide.md` | Step-by-step practice guide |

## Skills Demonstrated

- Filtering and navigating Windows Event Viewer
- Analysis of critical Event IDs (4624, 4625, 4688, 4720, 4672, 1102, etc.)
- Interpretation of Logon Types
- Account management event review
- Building simple investigation timelines
- Correlation with Sysmon and SIEM views

## Related Labs

Complements the **Sysmon**, **Active Directory**, **Wazuh SIEM**, and **Wireshark** home labs.
